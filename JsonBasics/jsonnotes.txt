JSON - Javascript Object Notation 
It is a lightweight data-format used to store and exchange data between:
Frontend -> Backend
Backend -> APIs
Backend -> AI models
Types of JSON are:
1. strings -> "helllo", "Sagar Tamang", "somthing" etc
2. Numbers -> 234,334,223,65,2,2,1.2e5, (33e-4,7.9e9) scientific numbers - exponential 
3. Boolens -> True and False
4. Null -> null
5. Arrays -> [1,3,2,4], [["a","b","c"], [1,3,5,3]] etc. 
6. Objects -> {"key":"value",
                "key2": "vlaue2",
                "key3": 34
              }
